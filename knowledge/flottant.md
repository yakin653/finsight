# Flottant

## Définition
Le flottant est la part des actions réellement échangeable. Un faible flottant rend le cours plus nerveux.

## Exemple
Un gros actionnaire stable réduit le nombre de titres en circulation.

## Pièges fréquents
Prendre la capitalisation totale pour la liquidité.

## Version débutant
Peu de titres libres, mouvements plus secs.

## Version expert
Les indices utilisent souvent la capitalisation flottante.

## Quiz
Question: Le flottant désigne :
- A. les actions réellement échangeables
- B. le dividende versé
Réponse: A
