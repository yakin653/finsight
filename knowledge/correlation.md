# Corrélation

## Définition
La corrélation dit si deux séries ont bougé ensemble. Proche de 1, elles ont varié dans le même sens ; proche de 0, peu de lien linéaire.

## Exemple
Deux actions du même secteur sont souvent plus liées qu'une action et une obligation.

## Pièges fréquents
Conclure qu'une corrélation passée restera.

## Version débutant
Elle décrit un lien observé, pas une cause.

## Version expert
Elle ne capture pas les liens non linéaires.

## Quiz
Question: Une corrélation élevée veut dire :
- A. des variations passées dans le même sens
- B. un même bénéfice
Réponse: A
