# Pulse Score

## Définition
Le Pulse Score résume trois lectures du passé : la position face aux moyennes, la stabilité et le repli. La probabilité du modèle n'entre pas dans le score.

## Exemple
Un score plus haut décrit une fenêtre plus calme et mieux placée, pas un ordre.

## Pièges fréquents
Le prendre pour une note d'achat.

## Version débutant
Trois morceaux du passé, réunis en une note.

## Version expert
Les poids sont ceux de l'application : position, stabilité, repli.

## Quiz
Question: Le Pulse Score n'utilise pas :
- A. la probabilité du modèle
- B. les cours passés
Réponse: A
