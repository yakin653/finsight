# Gap

## Définition
Un gap est un trou entre la clôture précédente et l'ouverture suivante. Le marché n'a pas coté les prix intermédiaires.

## Exemple
Une nouvelle publiée la nuit peut ouvrir loin du dernier cours.

## Pièges fréquents
Supposer que tous les prix entre les deux ont été échangés.

## Version débutant
Le cours saute, il ne passe pas par toutes les valeurs.

## Version expert
Un stop peut alors être exécuté au-delà du seuil.

## Quiz
Question: Un gap est :
- A. un saut entre deux prix sans échanges entre eux
- B. une moyenne mobile
Réponse: A
