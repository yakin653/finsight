# Bénéfice par action

## Définition
Le bénéfice par action répartit le résultat net sur les actions. Il baisse si le nombre d'actions augmente, même à résultat égal.

## Exemple
Un rachat d'actions peut le faire monter sans hausse du bénéfice total.

## Pièges fréquents
Le confondre avec le dividende versé.

## Version débutant
Résultat divisé par le nombre d'actions.

## Version expert
Les éléments exceptionnels peuvent le déformer sur un trimestre.

## Quiz
Question: Le bénéfice par action dépend :
- A. du résultat et du nombre d'actions
- B. seulement du volume
Réponse: A
