# Frais

## Définition
Les frais (courtage, spread, gestion) se retranchent du résultat. Un petit écart répété pèse sur une longue durée.

## Exemple
Un ETF cher à détenir peut annuler une partie de l'indice suivi.

## Pièges fréquents
Comparer des performances brutes de frais.

## Version débutant
Chaque coût réduit ce qui reste.

## Version expert
Les frais de change s'ajoutent sur un titre coté dans une autre monnaie.

## Quiz
Question: Les frais :
- A. réduisent le résultat
- B. augmentent le dividende
Réponse: A
