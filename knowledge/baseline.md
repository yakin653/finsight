# Baseline toujours hausse

## Définition
La baseline « toujours hausse » prédit une séance positive à chaque fois. Elle sert de repère simple : un modèle utile devrait la dépasser clairement.

## Exemple
Si le modèle n'est pas au-dessus, il n'a pas montré d'avantage.

## Pièges fréquents
Présenter un taux proche de un sur deux comme une compétence.

## Version débutant
Le repère naïf dit « hausse » tout le temps.

## Version expert
L'écart se lit dans le fichier d'évaluation, pas dans une promesse.

## Quiz
Question: La baseline sert à :
- A. comparer le modèle à une règle naïve
- B. choisir un titre
Réponse: A
