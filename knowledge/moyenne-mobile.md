# Moyenne mobile

## Définition
Une moyenne mobile est la moyenne des dernières clôtures sur une fenêtre fixe. Elle décrit le passé, elle ne prévoit pas.

## Exemple
Une fenêtre courte suit le cours de plus près qu'une fenêtre longue.

## Pièges fréquents
La lire comme un objectif de prix.

## Version débutant
C'est une moyenne des cours déjà passés.

## Version expert
Elle est retardée : le virage du cours apparaît après coup.

## Quiz
Question: Une moyenne mobile utilise :
- A. des clôtures déjà observées
- B. les bénéfices futurs
Réponse: A
