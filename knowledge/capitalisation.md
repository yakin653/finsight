# Capitalisation boursière

## Définition
La capitalisation est le cours multiplié par le nombre d'actions. Elle mesure la taille cotée, pas la trésorerie.

## Exemple
Deux sociétés au même cours peuvent avoir des capitalisations très différentes.

## Pièges fréquents
Comparer des cours entre eux sans regarder le nombre de titres.

## Version débutant
Cours fois nombre d'actions.

## Version expert
La capitalisation flottante exclut les blocs difficilement vendables.

## Quiz
Question: La capitalisation est :
- A. cours multiplié par le nombre d'actions
- B. le chiffre d'affaires
Réponse: A
