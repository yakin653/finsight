# Matière première

## Définition
Une matière première est un bien physique coté, souvent via un contrat à terme. Le prix reflète l'offre, la demande et le stockage.

## Exemple
Le pétrole et l'or ne réagissent pas aux mêmes nouvelles.

## Pièges fréquents
Oublier que le contrat à terme n'est pas le baril livré chez soi.

## Version débutant
Le cours suit un bien physique, pas une société.

## Version expert
Le report ou le déport change le rendement d'une position roulée.

## Quiz
Question: Une matière première cotée est :
- A. un bien physique, souvent via un contrat
- B. une action de banque
Réponse: A
