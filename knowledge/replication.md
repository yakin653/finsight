# Réplication d'un ETF

## Définition
La réplication physique détient les titres de l'indice. La réplication synthétique utilise un contrat avec une contrepartie.

## Exemple
Le synthétique ajoute un risque de contrepartie que le physique n'a pas de la même façon.

## Pièges fréquents
Les traiter comme équivalents sans lire le prospectus.

## Version débutant
Physique : les titres sont dans le fonds. Synthétique : un contrat.

## Version expert
Le collatéral du contrat doit être compris, pas ignoré.

## Quiz
Question: La réplication synthétique ajoute :
- A. un risque de contrepartie
- B. une garantie de l'État
Réponse: A
